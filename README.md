
# Python Exam Preparation Portal

A web-based learning application developed using Python and Streamlit to help students prepare for Python programming examinations.

## Features

- **Syllabus Viewer:** Browse units, chapters, and topics.
- **Chapter Preparation Quiz:** Attempt multiple-choice questions (MCQs), check scores, and read explanations.
- **Coding Practice Lab:** Explore programming exercises and sample solutions.

## Technologies Used

- Python
- Streamlit
- NumPy
- Pandas
- Matplotlib
- Tkinter

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/aditimittal1605-eng/python-exam-preparation-portal.git
```

### 2. Open the project folder

```bash
cd python-exam-preparation-portal
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run dd.py
```

The application will open in your web browser.
